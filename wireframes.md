# Wireframes (descricao das telas)
 
## Login
Campos: e-mail, senha. Botao Entrar.
 
## Agenda
Lista dos agendamentos do dia, com cliente, profissional, servico e horario.
Botao "Novo agendamento".
 
## Novo agendamento
Campos: cliente, profissional, servico, data e hora. Botao Agendar.
 
## Cadastro de clientes / profissionais / servicos
Lista dos itens cadastrados + botao para adicionar um novo.
